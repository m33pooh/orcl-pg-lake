# Data Lake Architecture (Oracle 23ai Free + PostgreSQL + n8n)

โปรเจกต์นี้เป็นการจำลองสถาปัตยกรรมสำหรับระบบที่ใช้ **Oracle 23ai Free** เป็นฐานข้อมูลหลักสำหรับระบบที่ต้องการความเร็ว (OLTP) และใช้ **PostgreSQL** เป็น Data Lake (OLAP) สำหรับเก็บข้อมูลประวัติศาสตร์ขนาดใหญ่ โดยมี **n8n** ทำหน้าที่เป็นระบบอัตโนมัติ (ETL) ในการดูดข้อมูลข้ามฐานข้อมูล

---

## 🏢 ตัวอย่าง 4 แอปพลิเคชันที่ใช้งานสถาปัตยกรรมนี้

เพื่อให้เห็นภาพการจัดการข้อมูลภายใต้ข้อจำกัดพื้นที่ 12 GB ของ Oracle นี่คือตัวอย่าง 4 ระบบที่เชื่อมต่อเข้ากับสถาปัตยกรรมนี้:

### 1. ระบบร้านค้าออนไลน์ (E-Commerce Web App)
* **ข้อมูลที่เกิด:** ข้อมูลลูกค้า, ตะกร้าสินค้า, คำสั่งซื้อ (Orders), สถานะจัดส่ง
* **Oracle (Hot Data):** เก็บข้อมูลโปรไฟล์ลูกค้าทั้งหมด และคำสั่งซื้อที่ "ยังดำเนินการอยู่" หรือสั่งซื้อภายใน 1 ปีล่าสุด เพื่อให้ลูกค้าเปิดดูประวัติได้รวดเร็ว
* **PostgreSQL (Cold Data):** เก็บประวัติคำสั่งซื้อที่จัดส่งสำเร็จแล้วและมีอายุเกิน 1 ปี เพื่อนำไปทำ Data Analytics (เช่น หาสินค้าขายดีประจำปี) โดยไม่ต้องเปลืองพื้นที่ Oracle

### 2. ระบบกระเป๋าเงินดิจิทัล (Payment & Wallet API)
* **ข้อมูลที่เกิด:** ประวัติการเติมเงิน, โอนเงิน, ตัดบัตรเครดิต (Transaction Logs)
* **Oracle (Hot Data):** เก็บข้อมูลยอดเงินคงเหลือ (Balance) และประวัติการทำธุรกรรมย้อนหลัง 3-6 เดือน ซึ่งเป็นช่วงเวลาที่ผู้ใช้มักจะกดเข้ามาดูบ่อยที่สุด
* **PostgreSQL (Cold Data):** ดูดข้อมูล Transaction รายวันไปเก็บสะสมไว้ เพื่อใช้ในการตรวจสอบบัญชี (Reconciliation) สิ้นเดือน หรือส่ง Report ให้ทีมบัญชีผ่าน BI Tools (เช่น Metabase/Tableau)

### 3. ระบบดูแลลูกค้า (CRM & Helpdesk Dashboard)
* **ข้อมูลที่เกิด:** ประวัติการแชท, การเปิด Ticket แจ้งปัญหา, ความพึงพอใจลูกค้า
* **Oracle (Hot Data):** เก็บสถานะ Ticket ที่กำลังเปิดอยู่ (Open/Pending) ข้อมูล Master Data ของลูกค้า เพื่อให้ทีม Support ทำงานได้รวดเร็วแบบ Real-time
* **PostgreSQL (Cold Data):** เมื่อ Ticket ถูกปิด (Resolved) เกิน 30 วัน n8n จะดูดข้อมูลข้อความแชทและรายละเอียดปัญหาไปเก็บที่ Data Lake เพื่อนำไปเทรน AI หรือวิเคราะห์ปัญหาที่เกิดซ้ำ

### 4. ระบบเก็บประวัติความปลอดภัย (Audit & Security Logging)
* **ข้อมูลที่เกิด:** ประวัติการ Login, IP Address, API Request Payload (App Logs)
* **Oracle (Hot Data):** เก็บ Log การใช้งานระบบเฉพาะ **7 ถึง 30 วันล่าสุด** เท่านั้น (เพราะ Log เป็นข้อมูลที่โตไวและกินพื้นที่ 12 GB เร็วที่สุด)
* **PostgreSQL (Cold Data):** n8n ทำการกวาด Log ของเมื่อวาน (Daily Batch) ไปใส่ใน PostgreSQL ทุกคืน เพื่อเก็บรักษากฎหมาย พ.ร.บ. คอมพิวเตอร์ (เก็บขั้นต่ำ 90 วัน - 1 ปี) และสั่ง Delete Log เก่าออกจาก Oracle ทันทีเพื่อคืนพื้นที่
